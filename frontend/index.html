Frozen Lake

The classic 4×4 slippery gridworld. The agent has four actions (up, down, left, right) and, on ice, slips to a perpendicular direction — so each move is a 3-way probabilistic bet. Navigate from S to G without falling into a hole.

Russell & Norvig Grid World

The textbook 3×4 MDP from Artificial Intelligence: A Modern Approach. Actions are unreliable (80% intended, 10% each side slip), every step costs −0.04, a wall blocks the middle, and the board ends in a +1 goal or a −1 pit. Find the optimal path that values the shortcut risk.
